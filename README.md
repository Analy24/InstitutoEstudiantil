# ArticulApp - Sistema de Articulación y Gestión

Plataforma web integral para la articulación de la educación media técnica (grados 10° y 11°) con el Instituto y el sector empresarial.

## Características Técnicas
- **Frontend:** React + Vite SPA
- **Backend:** Node.js + Express API REST
- **Persistencia:** SQLite / MySQL InnoDB
- **Autenticación:** JWT con control de acceso por roles (RBAC)
- **Despliegue:** Contenedor Docker Multi-Stage optimizado
